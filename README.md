# 👑 Queens · 皇后谜题

复刻 LinkedIn Queens 玩法的网页小游戏，**单文件、零依赖、离线可玩**。

## 🎮 开始游戏

直接双击打开 [index.html](index.html) 即可（或拖进任意现代浏览器）。

## 📜 规则

您的目标是在**每行、每列和每个颜色区域中正好有一个 Queen**。

两个 Queen **不能彼此相邻**，对角线相邻也不行。

每一局谜题都由内置生成器现场生成，并经过求解器验证**唯一解**；每个颜色区域颜色各不相同。

## 🖱️ 操作

| 操作 | 效果 |
|---|---|
| **单击**格子 | 放置 X（标记无法放置 Queen 的位置） |
| 再次单击 X | 取消标记 |
| **双击**格子 | 放置 Queen |
| 单击已有 Queen | 收回 Queen |
| **右键**点击 | 直接放置/收回 Queen（桌面端快捷） |

没有自动标记：只有你手动打上的 X 才会出现，和 LinkedIn 一致。

放置冲突的 Queen 会**变红抖动**提示；放满且无冲突即胜利，附计时与撒花 🎉。

## 🎚 难度

6×6 简单 · 7×7 · 8×8 · 9×9 · 10×10 · 11×11 大师，随时切换。

## 🧠 谜题是怎么生成的（技术说明）

1. 随机回溯生成一个满足全部约束的「主解」（每行每列各一个、互不相邻）；
2. **加权距离场（Voronoi）生长**：每个种子带随机强弱与偏移、每格再加轻微噪声，按加权曼哈顿距离分格——区域**大小参差、边界互相咬合**；
3. **连通修复 + 凸起平滑**：断开的小块并入邻居，三面被同一色区包围的「凸起单格」消除；
4. **再平衡**：超大区域吐格子、过小区域借格子，把面积压进合理区间；
5. 用回溯求解器数解：若存在多余解，把多余解的 Queen 格**重划入相邻色区**精确消灭之，配合随机扰动跳出僵局，迭代到**唯一解**；
6. **面积抛光**：唯一解达成后，继续把过大的区域拆给邻居，每步用求解器验证唯一性不被破坏。

实测 6×6–9×9 唯一解率 100%，大盘 95%，极端情况限时退化为多解谜题，仍可正常游玩。每个颜色区域颜色互不相同，相邻区域优先分配对比最强的颜色。
